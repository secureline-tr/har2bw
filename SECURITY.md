# Security

Report vulnerabilities privately to the repository owner. Do not post real HAR records, customer details, cookies, tokens or generated customer policies in issues or pull requests.

Treat HAR input as untrusted and keep it local. Review every candidate; a successful response does not establish authorization. Verify backend session and object authorization, query constraints, upload controls and trusted client IP configuration. Never automatically deploy generated drafts. Preserve WAF protections and test rollback.

This private repository contains synthetic test data only.
